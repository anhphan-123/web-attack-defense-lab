# Web Attack & Defense Lab

A hands-on Purple Team security lab focused on web attack simulation, WAF-based detection and prevention, and security monitoring using Wazuh SIEM.

## Technologies

Burp Suite · OWASP Juice Shop · Nginx · ModSecurity · OWASP CRS · Python · Wazuh
